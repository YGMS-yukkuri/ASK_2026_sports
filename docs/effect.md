# エフェクト仕様について

## エフェクトの概要
エフェクトは、ユーザーが特定のアクションを行った際に表示される視覚的な効果やアニメーションのことを指します。これにより、ユーザー体験が向上し、アプリのインタラクションがより魅力的になります。
## エフェクトの種類
1. **投稿エフェクト**: ユーザーが投稿を行った際に表示されるエフェクト。例えば、投稿が成功したことを示すアニメーションや、投稿内容が画面に表示される際のエフェクトなどがあります。
2. **リアクションエフェクト**: ユーザーがリアクションを行った際に表示されるエフェクト。リアクション内容が画面に表示される際のエフェクトなどがあります。

### エフェクト
- 投稿が表示される際、投稿の周囲にエフェクトを表示する(投稿者も受信者も両方)
- リアクションが表示される際、画面の周囲にエフェクトを表示する(リアクションに対応した絵文字を数*4くらいで飛ばす)(投稿者も受信者も両方)
