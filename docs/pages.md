# 掲示板として使用するページの内容を記述するためのドキュメントです。
## ページ構成
- **/**: メインページ - すべての投稿を表示
- **/post**: 投稿ページ - 新しい投稿を作成するためのフォーム
- **/admin**: 管理ページ - 投稿の管理や削除などの機能

## ページ内容
### メインページ (/)
- 投稿の一覧表示
- 各投稿には、投稿内容、投稿者のニックネーム、投稿日時、画像（ある場合）が表示される。
- 投稿は新しい順で、かつページネーション機能を実装することで、投稿が多くなっても見やすくする。
- 各投稿は、いいねなどの様々なリアクションをすることができる。
    - リアクションは、炎、ハート、いいね、驚き(!?)の4種類を用意する。
    - リアクションの数は、それぞれ投稿の下に表示される。
    - リアクション数は、リアルタイムで更新されるようにする（WebSocketを使用）。
- 新規投稿など、データ更新があった場合、リアルタイムで更新されるようにする（WebSocketを使用）。
- 端末IDは、投稿データとして保存されているが、メインページでは自分の投稿を内部的に判別するのみで、表示しない。

### 投稿ページ (/post)
- 投稿フォーム
    - ニックネーム入力欄（必須）
    - 投稿内容入力欄（必須）
    - 画像アップロード機能（任意）
- 投稿ボタン
- 投稿後、メインページにリダイレクトされる。(投稿内容はリアルタイムで反映される)
- 自分の投稿は、薄く水色などの背景色をつけるなどして、他の投稿と区別できるようにする。
- 自分の投稿はリアクション可能で、編集や投稿削除はできないようにする。(/adminで管理者が削除可能)
- 投稿内容の文字数制限は、200文字にする。
- 画像や動画のアップロードは、1投稿につき最大1枚までとする。画像のサイズは、1枚あたり20MB以下に制限する。
- 画像のアップロードは、サーバーに保存する方法とする。アップロードされた画像は、./data/images/ディレクトリに保存される。
- 画像のURLは、./data/posts.jsonの投稿データに保存される。
- 投稿内容の編集機能は実装しない。また、アカウントは不要として、ニックネームを用いて投稿できる。
- 初回投稿時にlocalStorageにニックネームを保存し、次回以降の投稿で自動的に入力されるようにする。
- 初回アクセス時、localStorageにニックネームが保存されていない場合は、ニックネーム入力欄を空欄にする。
- 初回アクセス時、localStorageにランダム生成の端末IDを保存し、投稿データに端末IDも保存することで、同一端末からの複数投稿を識別できるようにする。

### 管理ページ (/admin)
- 投稿の管理機能
    - 投稿の一覧表示
    - 各投稿には、投稿内容、投稿者のニックネーム、投稿日時、端末ID、画像（ある場合）が表示される。
    - 各投稿に削除ボタンを設置し、管理者が不適切な投稿を削除できるようにする。
    - 削除された投稿は、./data/posts.jsonからも削除されるようにする。
    - 削除された投稿は、メインページからもリアルタイムで消えるようにする（WebSocketを使用）。
- 管理者認証は、簡易的なパスワード認証を実装する。パスワードは、環境変数などで管理する。
- 管理ページへのアクセスは、認証されたユーザーのみとする。
