# 体育祭掲示板仕様等

- **プロジェクト名**: [STEM研究部体育祭専用掲示板]
- **バージョン**: [v0.1]
- **作成日**: [2026-05-25]
- **作成者**: [YGMS-yukkuri]

## 概要
- 体育祭で使用する専用掲示板の開発プロジェクト。部活動対抗リレーの際にリンクを掲示し、観戦者がリアルタイムで感想や応援メッセージを投稿できるようにすることを目的とする。

## 目的・ゴール
- **目的**: 体育祭でSTEM研究部として、リアルタイムで感想や応援メッセージを投稿できる専用掲示板を開発する。
- **ゴール（定量）**:
  - 体育祭当日に掲示板が正常に稼働すること。
  - 参加者からの投稿数が**100**件以上になること。
  - 掲示板の**投稿/受信**のレスポンスタイムが1秒以内であること。
  - リアルタイムで投稿が反映されること。
  - 視覚効果を用いて、部活対抗リレーの盛り上がりを助長すること。

## 背景・課題
- 実態がよくわか伝わっていないSTEM研究部の活動を、体育祭の場でアピールするための手段が限られている。
- 既存の掲示板サービスは、体育祭の特定のニーズ（リアルタイム性、視覚効果など）に対応していない。
- 体育祭当日に多くの参加者がアクセスすることが予想されるため、パフォーマンスや可用性の確保が課題となる。

## 対象ユーザー／ステークホルダー
- 利用者母数: 体育祭参加者(
    - 学生: 約1000人
    - 保護者: 約500人
    - 教職員: 約100人
)
- 利用者推定: 200人以上の同時接続

## 主要機能
1. 管理者機能 — 掲示板の管理、投稿のモデレーションなど
2. 投稿機能 — テキスト、画像、絵文字の投稿(リアルタイムで反映)
3. 表示機能 — 投稿の一覧表示、リアルタイム更新、視覚効果の適用
4. 更新機能 — 投稿の投稿・削除をリアルタイムでの反映
注釈: 投稿内容の編集機能は実装しない。また、アカウントは不要として、ニックネームを用いて投稿できるようにする。

## 非機能要件
- パフォーマンス: POST/GETリクエストのレスポンスタイムは1秒以内
- セキュリティ: 投稿内容のモデレーション機能
- 可用性／運用: 体育祭当日に24時間稼働すること
- スケーラビリティ: 同時接続200人以上に対応できること
